# Techora

Techora is a modern blog platform for exploring technology, AI, gaming, movies, apps, sports, internet culture, and interesting digital stories.

## Live Website

https://techorahc.netlify.app/

## Features

- Modern responsive blog design
- Multiple article categories
- Featured and latest articles
- Topic-based article exploration
- Sanity CMS for content management
- Responsive design for mobile and desktop

## Tech Stack

- Next.js
- Sanity CMS
- JavaScript
- Tailwind CSS

## Content Management

All blog content is managed through Sanity CMS, making it easy to create, edit, and publish articles.

## Deployment

Frontend: Netlify  
CMS: Sanity
